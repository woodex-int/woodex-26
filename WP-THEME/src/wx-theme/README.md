# WX Theme 1.0.0 — parent

Impreza is a **reference**. This theme does not load us-core, WPBakery, or Slider Revolution.

## Upload

`WP-THEME/dist/wx-theme.zip` → Appearance → Themes → Upload.

Pair with `woodex-core.zip` + Elementor Free + Xpro.

## After activate

1. Plugins: Elementor, Xpro, Woodex Core  
2. Permalinks → Post name  
3. Elementor → Flexbox Container On  
4. Tools → Woodex Setup  
5. Xpro Theme Builder (optional): Header / Footer / Single service / Single study / 404  

## Templates included

- PHP chrome header + mega + footer (works before Theme Builder)  
- `single-woodex_service.php` · `single-woodex_study.php` · `single-woodex_location.php`  
- Matching archives  
- Skin: `assets/skins/woodex-interior/tokens.json`

Home 3-slide and 3D Studio cine stay locked. No HTML widget.
