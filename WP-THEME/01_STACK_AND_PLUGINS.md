# Stack and plugins — researched recommendation

Install **this list only**. Disable unused Xpro widgets after install.

## Theme

| Item | Source | Role |
|---|---|---|
| **WX Theme** (`src/wx-theme`) | we write | Parent. Impreza-shaped folders. Elementor canvas. Tokens + chrome. |
| Hello Elementor + child `woodex` | fallback | Use only if you still want Hello as parent. |
| Impreza / us-core / WPBakery | GitHub reference only | Do not activate. |

Do not use Astra, Ocean, Woodmart, or a furniture marketplace theme. They fight Woodex chrome.

## Required plugins (production)

| Plugin | Cost | Why |
|---|---|---|
| Elementor | Free | Containers, typography, basic widgets |
| Xpro Elementor Addons | Free (WP.org) | Theme Builder, mega menu, 50+ widgets, floating, template import |
| woodex-core | We write | CPT, 5 custom widgets, REST brief, schema |
| Rank Math SEO | Free | Titles, sitemap, breadcrumbs. Configure, do not bloat. |
| WPForms Lite | Free | Contact/Start if you do not want only the Woodex Brief widget |

## Staging only

| Plugin | Cost | Why |
|---|---|---|
| Novamira | Free | MCP / agent PHP+files+DB. **Staging.** Production only after you accept exec risk. |
| Novamira Pro | Paid | Elementor/ACF abilities + memory. Optional. Not a design pack. |

## Do not install (unless a later command names a hole)

- Essential Addons + HappyAddons + Plus Addons + ElementsKit **together** with Xpro  
- Smart Slider 3 / MetaSlider / Revolution  
- Elementor HTML widget usage (policy, not a plugin)  
- Fake review plugins, Instagram feed, “award” tickers  
- Page builders besides Elementor  
- Nulled / weadown copies of Pro plugins  

## Optional later (one at a time)

| If this fails | Then consider |
|---|---|
| Xpro mega is weak at 5 columns | ElementsKit Lite mega **or** Max Mega Menu — remove Xpro mega |
| Xpro Theme Builder bugs | Header Footer Elementor (UAE free H/F) |
| Need native Elementor Form + Theme Style | Elementor Pro — replaces WPForms + some Xpro theme parts |
| Dynamic loops for studies | Crocoblock JetEngine — heavy; only if CPT singles are not enough |

## Xpro widgets to **enable** for Woodex

Heading, Button, Image, Icon Box, Accordion, Tabs, Counter, Gallery, Team (roles only, no fake names), Dual Button, Step Flow / Info List, Post Grid (insights archive), Promo Box, Business Hours, Google Maps, Nav Menu, Mega Menu.

## Xpro widgets to **keep off**

Particles, smoke, device slider (unless 3D page needs it), pricing tables with fake $ / sq ft, testimonial carousel until you have quotes, WooCommerce set (Woodex is not a shop).

## Multi Layer Slider

Xpro Multi Layer Slider is **Pro**. Do not depend on it. Home uses **Woodex Hero Slider** in `woodex-core`.
