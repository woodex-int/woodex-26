# WOODEX-26

Woodex Interior static frontend — **HTML5 + Tailwind CDN + `css/theme.css` + `js/app.js`**.

## Run locally

```bash
cd WOODEX-26
python3 -m http.server 8080 --bind 0.0.0.0
```

## Deploy

Upload this folder as the site root (Hostinger / any static host).

- **Vercel:** import the folder — `vercel.json` is included  
- **Netlify:** publish `.` — `netlify.toml` sends unknown routes to `404.html`  
- **Hostinger / Apache:** `.htaccess` sets `ErrorDocument 404 /404.html`  
- **Sitemap:** `https://woodex.interior/sitemap.xml`  
- **Robots:** `robots.txt`

Change the `https://woodex.interior` host in `sitemap.xml`, `robots.txt`, and each page’s canonical / OG / JSON-LD when the live domain is final.
