## 3 · Complete goal set

### 3.1 Business goals (from business model — internal targets, never published)
- Qualified enquiries: 40+/month via WhatsApp + forms; close rate 12–18%
- Priority emphasis: office fit-out (rank 1) · pharmacy (2) · retail (3) · restaurant (4)
- Every service page converts to: WhatsApp brief (primary) → start-your-project form (secondary)

### 3.2 SEO goals (per SEOMAP)
- Title ≤60 with primary keyword in first 3 words; description 150–160 CTA-flavored
- One H1 per page with primary keyword; semantic H2/H3 from the brief's section names
- 2–3 in-content sibling links per page + hub link + one cross-family link (3d-studio / projects / insights)
- Schema per page: Service + FAQPage (from page FAQs) + BreadcrumbList, fact-locked provider
- No cannibalisation: one page = one keyword intent (architecture vs drawings vs space-planning strictly differentiated)

### 3.3 Brand goals (every page defines Woodex)
- Quiet Authority voice: precise verbs, one idea per sentence, no banned phrases
- The path on every page: Requirement → Drawings → 3D → BOQ → Build (Cost-Lock)
- Proof language: 200–500 projects · 10+ years founder-led · in-house Woodex Furniture™ · Wellstar = only named client (pharmacy)
- Every page ends with a UNIQUE CTA variant — never a repeated template line

### 3.4 Content-integrity goals
- Copy from the page's docker brief only, tightened in studio voice; old page copy never reused
- Zero invented facts; every unconfirmed item `[CONFIRM]`; pricing HELD (no PKR anywhere)
- Unique section layout per page (see per-page plans Part 2) — no two pages share the same skeleton
- 600–900 words on page per MASTER §6.3

### 3.5 QA goals (definition of done, per page)
- 1440 + 390: zero overflow, reveals fire, contrast ≥4.5, links 200, no page errors
- Tag balance + JSON-LD parse + FAQ accordion + nav active-state checks
- Voice sweep + fact sweep + no-PKR sweep before commit
