# 00. PURPOSE

This file is the master content instruction for the Woodex Interior website.

The agent must use this document to rewrite and complete the website content while preserving the approved frontend design and section structure.

The objective is not to make Woodex sound like a generic interior-design company.

The objective is to make the website clearly communicate:

**DESIGN → VISUALIZE → PLAN → BUDGET → BOQ → EXECUTE → DELIVER**

The most important message:

# DESIGN IS NOT DECORATION.
# DESIGN IS THE FOUNDATION OF A SUCCESSFUL PROJECT.

Woodex has an in-house team of:
- interior designers
- 3D visualizers
- project / execution specialists
- craft / furniture capability
- site execution capability

Woodex can work from:
- a completely empty space
- an existing space
- an existing design
- a floor plan
- brand guidelines
- reference images
- a client concept

The website must explain the difference between these situations and show the appropriate Woodex route.
