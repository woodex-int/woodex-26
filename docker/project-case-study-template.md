# PART 1 — TEMPLATE INSTRUCTIONS & USAGE GUIDE

## 1.1 How to Use This Template

This is a **reusable template** for producing individual project case-study pages for the Woodex Interior portfolio. Each real project replaces the placeholders below with actual data. The template is designed to work across all service categories:

- **Renovation** projects (office, retail, healthcare, restaurant, residential, specialized)
- **Interior Design** projects (office, residential, retail, healthcare, restaurant)
- **Fit-Out** projects (office, retail, restaurant, healthcare, pharmacy)
- **Architecture** projects (residential, commercial, master planning)

## 1.2 Placeholder Reference

| Placeholder | Replace With | Example |
|-------------|-------------|---------|
| `[PROJECT_NAME]` | Client's project name or descriptive title | "Apex Pharma — Flagship Pharmacy Fit-Out" |
| `[PROJECT_SLUG]` | URL-friendly version | `apex-pharma-pharmacy-fit-out` |
| `[SERVICE_TYPE]` | Woodex service category | Pharmacy Fit-Out / Office Renovation / etc. |
| `[CLIENT_NAME]` | Client name (or "Confidential" if NDA) | Apex Pharma (Pvt.) Ltd. |
| `[CLIENT_TYPE]` | Client sector/category | Pharmacy Chain / Corporate Office / Restaurant |
| `[LOCATION]` | Project location in Lahore (or other city) | DHA Phase 5, Lahore |
| `[AREA_SQFT]` | Project area in square feet | 1,200 sq ft |
| `[DURATION]` | Project timeline | 6 weeks |
| `[YEAR]` | Year completed | 2024 |
| `[BUDGET_RANGE]` | Budget bracket (optional, with client permission) | PKR 3M–5M |
| `[CHALLENGE]` | Primary challenge or constraint | Limited space, tight deadline, compliance requirement |
| `[SOLUTION]` | How Woodex solved it | Custom layout, phased delivery, compliance-first approach |
| `[RESULT]` | Measurable outcome or client testimonial | Opened on time, 30% more display space, client testimonial |
| `[SERVICE_URL]` | Link to the relevant service page | `/pharmacy-fit-out/` |
| `[BEFORE_IMAGE]` | Before photo (shell/empty space) | Image filename |
| `[AFTER_IMAGE]` | After photo (completed project) | Image filename |
| `[DETAIL_IMAGES]` | Additional project photos (2–4) | Feature wall, reception, etc. |

## 1.3 Data Collection Checklist

Before writing a real case study, gather:

- [ ] Project name and client permission to publish
- [ ] Service type (renovation / design / fit-out / architecture)
- [ ] Location (area of Lahore)
- [ ] Area in square feet
- [ ] Timeline (weeks/months)
- [ ] Budget range (optional — ask client)
- [ ] Primary challenge or constraint
- [ ] Solution approach
- [ ] Result / outcome / testimonial
- [ ] Before photo (shell/empty/existing space)
- [ ] After photo (completed project)
- [ ] 2–4 detail photos (key features, before/after comparisons)
- [ ] Service page URL to link back to

# PART 2 — PAGE STRATEGY & SEO SPECIFICATIONS

## 2.1 Page Purpose

| Job | Purpose |
|-----|---------|
| **SEO** | Rank for "[service type] project Lahore", "[client type] [service] Lahore" — long-tail keywords with high conversion intent |
| **Education** | Show potential clients a real example of Woodex work — what was done, how it was done, what the result was |
| **Conversion** | Build trust through social proof; route the visitor to the relevant service page for their own project |

### Critical Keyword Strategy

Each case study targets:
- **Primary:** "[service type] project Lahore" or "[service type] [client type] Lahore"
- **Secondary:** "[service type] cost Pakistan", "[service type] portfolio", "Woodex [service type]"

Example for a pharmacy fit-out case study:
- Primary: "pharmacy fit-out project Lahore", "pharmacy interior project DHA"
- Secondary: "pharmacy fit-out cost Pakistan", "pharmacy interior portfolio", "Woodex pharmacy fit-out"

# PART 7 — IMAGE AND MEDIA BRIEF

## 7.1 Hero Image

| Property | Brief |
|----------|-------|
| **Subject** | Completed project — the hero shot that sells the work |
| **Mood** | Professional, polished, portfolio-quality |
| **Style** | Real photograph (preferred) or photorealistic 3D render |
| **Avoid** | Stock photos, incomplete work, low-quality phone shots |
| **Dimensions** | 1920 × 1080; 16:9 |

## 7.2 Before/After Images

| Property | Brief |
|----------|-------|
| **Before** | Shell space, empty room, or existing space before work began |
| **After** | Completed project from the same angle (ideal) or similar angle |
| **Consistency** | Same framing, lighting awareness — makes the comparison compelling |

## 7.3 Detail Images (2–4)

| Property | Brief |
|----------|-------|
| **Subject** | Key features of the project — reception, feature wall, kitchen, display, etc. |
| **Quality** | Professional photography or high-quality 3D renders |
| **Captions** | Each image needs a 1-line caption for accessibility and SEO |
