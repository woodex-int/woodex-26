# PART 1 — MASTER STRATEGY

## 1.1 Why Renovation Is a Highway

Renovation is Woodex Interior's **existing-space** market — distinct from new build and fit-out of shell space. Every business and homeowner with an old, dated or under-performing space is a renovation prospect. The market is everywhere because the inventory already exists.

| Statistic | Source / Basis |
|-----------|----------------|
| Existing-home upgrades | DHA + Bahria + Gulberg + Model Town replacement/downgrade cycle |
| Tenant improvement | Every leased commercial space renewed every 3–5 years forces refresh |
| Retail refresh | Brands refresh outlets every 2–3 years to stay engaging |
| Healthcare upgrade | Clinics, pharmacies, labs must upgrade to current DRAP/clinical standards |

## 1.2 The SEO Architecture Decision

One mega page *cannot* rank for all 30+ renovation sub-services. The master file therefore defines **8 separate URLs**:

```
/renovation/                    → HUB (this file's center)
/office-renovation/
/commercial-renovation/
/retail-renovation/
/healthcare-renovation/
/restaurant-renovation/
/residential-renovation/
/specialized-renovation/
```

**Why split:**
- Each URL owns its own title tag → 8× Google real estate instead of 1
- Each visitor lands on sector-relevant content → higher conversion
- Hub links to all siblings → link equity flows down
- Specialized services become a union page, not orphan keywords
- No cannibalization with existing pages (Office Fit-Out, Kitchen Design etc.) — cross-link, don't compete
