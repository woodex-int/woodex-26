## 5 · ON-PAGE PATTERN (every page, non-negotiable)

1. `Title ≤ 60`, unique + target keyword in first 3 words.
2. `Meta description 150–160`, CTA-flavored, no generic filler.
3. `H1 unique + target keyword` (one per page).
4. `H2/H3` semantic hierarchy, keyword variants only.
5. `First paragraph` includes primary keyword naturally.
6. `Internal links` 2–3 sibling pages per page (footer + in-content).
7. `Image alt` natural, no keyword stuffing.
8. `URL` lowercase, hyphenated, no parameters.
9. `Schema` injected per page type (Section 2 per-page schema).
10. `CTA band` at page end — WhatsApp primary + form secondary.
